# Andrei Loy — Portfolio

Personal portfolio of Andrei Loy, BS Information Technology student at Cebu Institute of Technology – University.

A static site: one `index.html` (HTML, CSS and vanilla JavaScript) plus images. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Deploy

Import this repository in Vercel with the **Other** framework preset. Leave the build command and output directory empty.
