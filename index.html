Featured project, 2026

CrediTOR

Transcript of Records verification system

Registrars issue each transcript with a document control number and a QR code. Anyone can scan the code or type the number to check whether the transcript is active, revoked or expired. Admins get a document registry, an audit trail with CSV export, and JWT sign-in.

The React frontend runs on Vercel and the Spring Boot API runs on Render in a Docker container. A GitHub Actions job keeps the server warm so visitors don't wait on a cold start.

    Project, 2026

    ChemLab

    Lab inventory and chemical request system for web and Android

    Students request chemicals, technicians approve or reject them, and admins manage users and watch a live audit feed. New inventory items fill in their details from PubChem, reports flag low-stock and expiring chemicals, and requests send email notifications.

    One Spring Boot REST API, organized by feature, serves both a React web app and a Kotlin Android app. Sign-in uses JWT with Google OAuth2.
